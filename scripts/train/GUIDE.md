# Pokémon Classifier — Training Guide

Train your own on-device TFLite model covering all **1,025 Pokémon** (Gens 1–9).  
The model runs entirely on-device using `react-native-fast-tflite` — no API calls, no internet needed at scan time.

---

## Scripts Overview

```
scripts/train/
├── 1_download_sprites.py          ← PokeAPI sprites + CDN art (~15–20 imgs/Pokémon)
├── 1b_download_google_images.py   ← pokemondb.net + pokemon.com CDN (~17 imgs/Pokémon)
├── 1c_google_images_playwright.py ← Google Images via real browser (~40 imgs/Pokémon)
├── 2_train_model.py               ← MobileNetV2 transfer learning → model.tflite
└── GUIDE.md                       ← this file
```

**Estimated time:**
| Step | Time |
|------|------|
| `1_download_sprites.py` | ~15 min |
| `1b_download_google_images.py` | ~5 min |
| `1c_google_images_playwright.py` | ~20–40 min |
| Train on Google Colab (T4 GPU) | ~60–90 min |

> **Always train on Google Colab** — it gives you a free T4 GPU. Local CPU training takes 8–12 hours.

## Step 1 — Download Sprites (run locally)

Downloads official artwork, HOME 3D renders, game sprites, and shiny variants for all 1,025 Pokémon from PokeAPI's GitHub CDN.

```bash
cd c:\Dev\pokedex\scripts\train
py -m pip install requests pillow
py 1_download_sprites.py
```

Creates `dataset/{pokemon_name}/` folders with up to 20 images per Pokémon.

---

## Step 1b — Download CDN Images (run locally)

Downloads additional images from **pokemondb.net** and **pokemon.com** — multiple game generations, shiny variants, and official artwork. No API key, no scraping. Very fast (~5 min).

```bash
py 1b_download_google_images.py
```

Adds ~17 more images per Pokémon to existing `dataset/` folders.

---

## Step 1c — Download Google Images (optional, run locally)

Uses a real Chromium browser (via Playwright) to search Google Images for each Pokémon and download real-world photos: anime screenshots, figures, plushies, cards, merchandise. This makes the model recognize Pokémon from a camera pointed at real objects.

### One-time setup
```bash
py -m pip install playwright pillow requests
py -m playwright install chromium
```

### Run
```bash
py 1c_google_images_playwright.py
```

- Runs **4 browser pages in parallel** for speed
- Downloads ~40 images per Pokémon
- If interrupted, set `START_FROM = 200` (or wherever it stopped) and re-run
- Set `HEADLESS = False` to watch the browser (useful if a captcha appears)

## Step 2 — Resize Images & Zip (run locally)

**This is critical** — raw downloaded images can be 30 GB+. Resize to 224×224 first:

```bash
py 1d_resize_dataset.py
```

This shrinks the dataset from ~30 GB → ~2 GB. Takes ~5 min with 8 threads.

Then zip:

```powershell
Compress-Archive -Path dataset -DestinationPath dataset.zip -Force
```

## Step 4 — Train on Google Colab

### 4a. Open Colab

Go to **[colab.research.google.com](https://colab.research.google.com)** → New notebook

### 4b. ⚠️ Set GPU runtime FIRST
**Runtime → Change runtime type → T4 GPU → Save**

### 4c. Run these cells in order

**Cell 1 — Mount Google Drive**
```python
from google.colab import drive
drive.mount('/content/drive')
```

**Cell 2 — Extract dataset from Drive**
```python
import zipfile, os, shutil

zip_path = "/content/drive/MyDrive/pokemon-train/dataset.zip"

print("Extracting...")
with zipfile.ZipFile(zip_path, "r") as z:
    z.extractall(".")
folders = os.listdir("dataset")
imgs = sum(len(os.listdir(f"dataset/{f}")) for f in folders if os.path.isdir(f"dataset/{f}"))
print(f"✅ {len(folders)} Pokémon, {imgs:,} total images")
```

**Cell 3 — Copy training script from Drive & run**
```python
import shutil
shutil.copy("/content/drive/MyDrive/pokemon-train/2_train_model.py", ".")
!pip install -q tensorflow pillow
!python 2_train_model.py
```

> Takes **60–90 min** on T4 GPU.

**Cell 4 — Save outputs back to Drive**
```python
import shutil
shutil.copy("model.tflite", "/content/drive/MyDrive/pokemon-train/model.tflite")

```

> Saving to Drive means you keep the model even if the Colab session expires.

## Troubleshooting

**`outputs:151` in logs** → Wrong model file in `assets/`. Copy the Colab output.

**Always shows same Pokémon** → `labels.json` in `assets/` doesn't match the one from training. Always copy both files together.

**`CUDA out of memory`** → Reduce `BATCH_SIZE = 16` in `2_train_model.py`

**Training too slow on Colab** → Runtime → Change runtime type → make sure T4 GPU is selected

**Model state shows `error`** → The `.tflite` file may be corrupted. Re-download from Colab.

**Playwright captcha** → Set `HEADLESS = False` in `1c_google_images_playwright.py` and solve it manually. Script will continue after.
